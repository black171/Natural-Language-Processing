## EDAB2724 Assignment 3: Bitcoin Tweet Topic Modelling

## Overview
This assignment uses text analytics and topic modelling to discover common themes in Bitcoin-related tweets and explore patterns in social media discussions.

## Key Activities
- Explore and preprocess tweet data.
- Clean text and prepare it for analysis.
- Apply Latent Dirichlet Allocation (LDA).
- Apply Non-negative Matrix Factorisation (NMF).
- Interpret and compare discovered topics.
- Investigate topic trends over time where timestamps are available.

## Tools and Technologies
Python, Jupyter Notebook, pandas, NumPy, scikit-learn and Matplotlib.

## Learning Outcomes
Develop skills in text preprocessing, unsupervised machine learning, topic interpretation and social media data analysis.
